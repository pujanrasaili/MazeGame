# 🌀 Maze Game

A visually interactive 2D Maze Game built using Java Swing, featuring multiple gameplay modes, dynamic level scaling, and a custom UI system.

---

## 🎮 Features

- 🧩 Procedurally generated mazes (recursive backtracking)
- 📈 Progressive difficulty with level-based scaling
- ⏱️ Timed mode with increasing pressure
- 🌫️ Fog of War (limited visibility gameplay)
- 🏆 Challenge mode (combined mechanics)
- 🎨 Custom-rendered UI (no game engine used)
- 🖥️ Interactive menu dashboard with mode selection

---

## 🕹️ Game Modes

| Mode        | Description |
|------------|------------|
| **Normal** | Classic maze experience |
| **Timed** | Complete the maze before time runs out |
| **Fog of War** | Limited visibility around the player |
| **Challenge** | Timed + Fog combined for maximum difficulty |

---

## 🎯 Controls

| Key | Action |
|-----|--------|
| ⬆️⬇️⬅️➡️ | Move player |
| R | Restart level |
| N | Next level |
| M | Back to menu |
| F | Toggle fog |
